XITM5229 Task 2 - SOP Portal (static website)

HOW TO VIEW
1. Extract the website folder.
2. Open index.html in a current web browser.
3. Use the navigation bar or cards to open each SOP.

FILES
- index.html: accessible single-page SOP portal and all policy content.
- styles.css: responsive layout and visual styling.

NOTES
This is a static demonstration site and does not require a server or database. Before organisational use, the facility must approve the policy text, replace generic role names as needed, add official contact details, and verify the recovery objectives against its business impact analysis.
